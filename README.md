# AI Insurance Based Fraud Detection

This repository contains the source code and resources for an AI-powered insurance fraud detection system. It includes modules for data preprocessing, model training, and a web interface for visualizing predictions.

## Project Structure
- `CSV/` – Sample datasets.
- `backend/` – Backend services and APIs.
- `frontend/` – Frontend UI.

## Setup
```bash
# Install dependencies
npm install
# Run the application
npm start
```
